Made for momentum

Useful help, right where you work.

AURA is an independent desktop project built around a simple idea: make AI assistance easier to reach while you study, create, code, or explore.

✦

Gemini-powered answers

Ask questions and switch between focused modes for study, creator work, interviews, concepts, and code.

▧

Screen and documents

Capture a screen or attach supported documents when you want context-aware help.

♫

Voices, your choice

Use optional ElevenLabs voices for spoken replies, with a local Windows speech fallback.

⌁

Floating companion

Keep AURA nearby, use compact mode, and bring it back with a keyboard shortcut where supported.

🎙

Speak naturally

Record a short voice request and let Gemini help interpret what you said.

⚙

Your own provider keys

AURA uses your provider accounts directly. You control keys, quotas, and provider billing.

Getting started

Up and running in three steps.

01 / DOWNLOAD

Get the Windows build

Download the latest published release from GitHub. If no release is available yet, check back after the first build is published.

02 / CONFIGURE

Add your Gemini key

Follow the included setup guide and store your own key locally. Never share your secret key or upload it with the app.

03 / MAKE IT YOURS

Choose how you work

Use chat, supported attachments, screen capture, voice input, and optional online speech.

Try the project

Meet your new desktop sidekick.

AURA is an evolving project. Review the release notes and requirements before installing. A public installer will appear here when a tested build is published.
