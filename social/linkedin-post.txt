I’ve been building **AURA AI** — a Windows desktop copilot designed to make AI assistance easier to reach while you’re already working.

Instead of another tab to keep open, AURA lives in a floating desktop window and brings together:

- Gemini-powered chat with focused modes for studying, coding, creator work, and interview practice
- Screen capture and document context when I need help with what’s on my desktop
- Voice input and optional ElevenLabs text-to-speech, with a local Windows speech fallback
- A compact interface, keyboard shortcut, and explicit app exit

I built it with Python, PySide6, Google’s Gen AI SDK, and the ElevenLabs SDK. Getting voice selection and shutdown behaviour right was a good reminder that a demo is only the beginning — the details matter when you want software to feel like a real application.

I’m now working on the next step: packaging AURA for Windows, documenting setup and privacy clearly, and publishing a simple download page.

It’s still an early-stage project, and it currently uses a bring-your-own-API-key model rather than a hosted backend. I’m testing the release workflow before calling it ready for general use.

GitHub: https://github.com/nilabh101/AURA-AI
